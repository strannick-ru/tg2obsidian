# tg2obsidian

Эта программа (далее — Бот) использует бесплатную функциональность бота Telegram для сохранения сообщений из группы Telegram в хранилище [Obsidian](https://obsidian.md) на локальном компьютере.

Используемая разметка Markdown подойдёт и для большинства [других программ](https://www.markdownguide.org/tools/), работающих с локальными файлами Markdown.

## Сценарий использования

- Вы _на ходу_ пишете, наговариваете или пересылаете сообщения в личную группу Telegram
- Бот получает новые сообщения из Telegram и сохраняет их в виде заметок, таким образов формируя входящий поток информации прямо в вашем хранилище заметок
- _Позже в спокойной обстановке_ вы обрабатываете эти заметки, разнося информацию из них в подходящие места в своём хранилище

## Возможности

- Возможен приём сообщений из одного или нескольких чатов Telegram.
- Для каждого чата можно указать отдельную папку хранилища Obdisian.
- Все сообщения группируются по дате — одна заметка на день/месяц/год (в соответствии с шаблоном имени заметки) — или хранятся в одной заметке.
- Каждое сообщение в заметке имеет заголовок с отметкой даты и времени (можно подавлять для частых сообщений).
- В зависимости он настроек сохраняется либо игнорируется форматирование сообщений.
- Для пересланных сообщений добавляется информация об источнике сообщения.
- Фотографии, анимации, видео и документы сохраняются в хранилище и встраиваются в заметку.
- Контакты сохраняются в виде YAML front matter и vcard.
- Для мест создаются ссылки на Google Maps и Яндекс.Карты.
- Есть возможность преобразовывать заметки с определенными ключевыми словами в задачу.
- Есть возможность принудительно превращать все сообщения чата в задачи через `/tasks on|off`.
- Есть возможность тегировать заметки с определенными ключевыми словами.
- Есть возможность распознавания текста с картинок. При этом Бот отправляет распознанный текст в виде ответа на исходное сообщение.
- Есть возможность распознавания речи из голосовых сообщений и аудиосообщений (локально через Whisper или через облачный OpenAI-compatible API). При этом Бот отправляет распознанный текст в виде ответа на исходное сообщение.
- После обработки сообщения бот добавляет к нему эмодзи OK.

## Установка и настройка

Инструкции ниже рассчитаны на пользователей Windows. Для пользователей Linux и MacOS процедура установки и настройки аналогична, но команды для запуска программ могут отличаться.

Расширенные инструкции см. на странице [extended_tg2obsidian_manual.ru](extended_tg2obsidian_manual.ru.md)

### Основные действия

1. Установите [Python](https://python.org). Матрица CI базовой установки включает Python 3.10–3.14 под Linux и Python 3.13 под Windows. У OCR и распознавания речи есть дополнительные требования; их совместимость эта матрица не проверяет.
2. Откройте терминал в каталоге проекта и создайте виртуальное окружение:

```shell
python -m venv .venv
```

Активируйте его в Windows (командная строка, cmd):

```bat
.venv\Scripts\activate.bat
```

Или в Linux/macOS:

```shell
source .venv/bin/activate
```

Затем установите базовые зависимости:

```shell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip check
```

Базовая установка не включает пакеты OCR и распознавания речи. Установите соответствующие необязательные зависимости ниже, только если включаете эти функции в `config.py`. Запускайте бота также из активированного окружения.

3. Создайте своего бота при помощи https://t.me/BotFather
4. Вставьте токен, полученный от `@botfather`, в соответствующую переменную в файле `config.py` и измените остальные параметры в `config.py` требуемым образом.
5. (Не обязательно). Добавьте созданного выше бота в приватную группу Telegram и сделайте администратором, чтобы он мог читать сообщения.
6. Запустите бота (см. раздел "Использование")
7. Отправьте команду `/start` вашему боту в Telegram. В ответе бот сообщит ваш id. Вставьте его в параметр `allowed_chats` в файле `config.py`. Несколько идентификаторов разделяйте двоеточием.

### Необязательно: proxy для Telegram

Если в вашей сети режется прямой доступ к Telegram, Бот может подключаться к Telegram Bot API через proxy.

Добавьте настройки proxy в `config.py`:

```python
telegram_proxy_url = "socks5h://your-proxy-host:1080"
telegram_proxy_login = ""
telegram_proxy_password = ""
```

Примечания:

- Оставьте `telegram_proxy_url` пустым, если хотите использовать прямое подключение.
- Поддерживаются форматы `socks5h://...`, `socks5://...`, `socks4a://...`, `socks4://...` и `http://...`.
- Если proxy требует авторизацию, заполните `telegram_proxy_login` и `telegram_proxy_password`.
- Proxy используется только для запросов к Telegram Bot API и для скачивания файлов из Telegram. Обычные внешние URL для preview через proxy не ходят.
- Для поддержки proxy нужен пакет `aiohttp-socks`, он уже добавлен в `requirements.txt`.

#### Как установить VPN и proxy

1. [Как установить полностью настроенный VPN на VPS](https://github.com/ClusterM/vpn-how-to)
2. [Как настроить SOCKS5 proxy на 3x-ui](SOCKS5-proxy-howto.md)

### Если требуется распознавание текста на картинках

1. В активированном окружении выполните `python -m pip install -r requirements-ocr.txt`.
2. Установите [Tesseract](https://github.com/tesseract-ocr/tessdoc), данные нужных языков и добавьте каталог исполняемого файла в PATH (tesseract.exe в Windows). Проверьте командой `tesseract --version`.
3. Установите `ocr = True` и настройте `ocr_languages` в `config.py`.

### Если требуется распознавание речи

Выберите один способ и установите его зависимости в активированном окружении:

- **Локальный Whisper:** выполните `python -m pip install -r requirements-voice-local.txt`. Установите [FFmpeg](https://ffmpeg.org/download.html), добавьте каталог исполняемого файла в PATH и проверьте командой `ffmpeg -version`. Установите `recognize_voice = True` и `stt_provider = "local"` в `config.py`. При первом запуске скачивается выбранная модель Whisper; Torch и модель могут потребовать значительного места на диске и оперативной памяти. Выбирайте версию Python, поддерживаемую одновременно [Whisper](https://github.com/openai/whisper#setup) и [PyTorch](https://pytorch.org/get-started/locally/): матрица CI базовой установки не подтверждает их совместимость. Для использования GPU следуйте инструкции установки Torch на сайте PyTorch.
- **Облачный STT:** выполните `python -m pip install -r requirements-voice-cloud.txt`. Установите `recognize_voice = True`, `stt_provider = "cloud"` и заполните `stt_base_url`, `stt_api_key`, `stt_model_name`, `stt_language` в `config.py` (OpenAI-compatible API). Аудио отправляется настроенному провайдеру; локальные Whisper, Torch и FFmpeg для этого режима не нужны.

Каждый необязательный файл зависимостей включает базовые зависимости. При необходимости можно установить несколько групп.

### Проверка установки без Telegram

В каталоге проекта, с активированным виртуальным окружением:

```shell
python -m pip check
python -m unittest discover -s tests -v
```

Тесты используют фиктивную конфигурацию и временный каталог, а сетевые подключения блокируют. Они проверяют импорт бота, создание прокси-сессий и HTML-парсер предпросмотра без настоящего токена, пакетов распознавания и скачивания моделей. Доставка и сквозная обработка сообщений не проверяются. GitHub Actions выполняет те же проверки на указанной выше матрице; наличие задания не означает успешного запуска — смотрите результаты во вкладке Actions репозитория.

## Использование

1. Отправляйте/пересылайте сообщения, которые должны попасть в ваше хранилище Obsidian, напрямую вашему боту или в свою приватную группу Telegram.

2. Запустите Бота:
```shell
python tg2obsidian_bot.py
```

- На постоянно работающем компьютере или на сервере Бота можно не выключать. Тогда он будет распознавать речь и заносить заметки в Obsidian в реальном времени.
- Если вы включаете компьютер только на время использования, запускайте Бота непосредственно тогда, когда нужно получить сообщения в Obsidian, а после получения всех сообщений закрывайте программу.

**Важно!** Telegram хранит [новые сообщения](https://core.telegram.org/bots/api#getting-updates) для ботов в течение 24 часов, поэтому Бот может получить сообщения только за последние 24 часа. Если от момента отправки сообщения до запуска Бота прошло более 24 часов, такое сообщение уже не будет получено Ботом.

### Команды бота

- `/start` — показывает id чата для `allowed_chats`.
- `/help` — помощь.
- `/set_folder <path>` — задать относительную папку для текущего чата.
- `/tasks on|off` — принудительно делать все сообщения чата задачами (с суффиксом задачи).

### Группировка по времени

Чтобы не повторять заголовок с временем при серии сообщений, добавьте `message_timestamp_interval` в `config.py` (секунды). Если сообщение пришло в пределах интервала, заголовок времени не добавляется.
